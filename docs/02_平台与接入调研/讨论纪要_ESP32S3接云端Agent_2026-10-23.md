# 讨论纪要：ESP32-S3 接云端 Agent 的技术路线

> 2026-10-23 | 老人导诊卡套项目 | 从"接 TiDB Link"到"用 Agent_link"的判断演进

---

## 一句话现状

硬件侧已找到官方开源方案：`Deotaland/Agent_link` 里有这块板子的完整板级支持（profile `waveshare-epaper-397-wifi`），实时语音全栈已实现，**首版可零固件改动**。待解决的是"赛事用哪个平台"这一个分叉。

## 过程与结论（五步）

| # | 输入 | 得出什么 | 后来被推翻/修正的 |
| --- | --- | --- | --- |
| 1 | `mem9-ai/tidblink-dev-guide` | TiDB Link 架构：密钥不上设备、设备不直连 REST、硬件控制只能经 Connector；提出 L0/L1/L2 三级落地 | "L2 两天成功率不到 40%"——后来发现 SDK 已实现，判断作废 |
| 2 | `you06/esp32-agent-lcd` | 确认存在旧版 Agent Stack API（`/api/**` + NDJSON），与新 `/api/v1/**` + SSE 不是一套 | "手机 App 是运行依赖"、"必须自研 MQTT/Connector"——均不成立 |
| 3 | Gamma 参赛指南页 | 拿到服务地址 `ventured-agent-stack.pingcap.cn`、Console 账号密码登录；核实该页是旧 API 快照 | — |
| 4 | 参赛方现成链路截图 | 确立"先验证现成链路、再谈自研"的原则，不先造通信协议 | "`/api/triage` 是保底"——它只是接口草案，无实现 |
| 5 | `Deotaland/Agent_link` | **本板官方板级支持在列**，WiFi 路线直连平台、不需要 App；语音走 `tidb-link.realtime.v1`，与第 1 步文档同源 | 全部收口到这一条 |

**关键转折**：第 5 步把前四步串起来了——Agent_link 的 WSS 子协议就是 `tidb-link.realtime.v1`，所以第 1 步读的协议文档不是白读，它是这套 SDK 的底座。之前判断"最难、最可能做不出来"的实时语音层，SDK 已经写完。

## 当前技术结论

| 项 | 结论 | 依据 |
| --- | --- | --- |
| 连接方式 | **只能 WiFi，没有 BLE** | `config.json`：`transport: WIFI`、`ble_name: null`；且 BLE 依赖未公开的手机 App |
| 是否需要 App | **不需要** | WiFi profile 直连平台，热点配网 + 6 位激活码 + 网页绑定 |
| 工具链 | **ESP-IDF 5.5.4，不是 Arduino** | 工程含 components / Kconfig profile / 自定义 partitions.csv，Arduino IDE 编不了；且该板不支持 IDF 6.1 |
| 首版固件改动 | **零改动** | 回复以纯文本上屏（≤1 KB，GB2312 全集 6763 字），导诊话术放得下 |
| 平台地址 | `bot.deotaland.cn`（硬编在 `platform_config.h`） | 与赛事 `pingcap.cn` 不同服务，是唯一分叉点 |

**能原样获得的能力**：热点配网 → 激活码 → 平台绑定 Agent → 会话列表/创建/选择 → 实时语音（Opus 16k 入 / 24k 出，PCM16 回落）→ 墨水屏显示 → OTA。墨水屏刷新策略已内建（快刷间隔 ≥2 秒、每 16 次全刷、BUSY 超时 20 秒、失败退避 30 秒、空闲休眠）。

## 未决问题（按优先级）

1. **赛题是否强制指定 Agent 平台？** 决定原样用 Deotaland，还是改 `BASE_URL` 走 `CONFIG_AGENT_LINK_REALTIME_DIRECT` 接赛事平台。
2. **平台侧有没有该 product 的语音 Agent 模板？** 验证记录里出现过 `code 1002 agent_template_unavailable`，会话创建会直接失败。不在我们手里。
3. **真机验收全部 pending**：TG28 电源轨、屏幕刷新与方向、按键极性、ES8311 电平、配网、激活、绑定、`session.ready`、双向语音、重启持久化，README 明写"构建成功不代表这些验证过"。
4. **product ID 文档冲突**：`products.json` 写 5，`config.json` notes 写 20（过期残留），构建以 5 为准。
