# 硬件量产成本测算（自发 PCB 方案）

日期：2026-10-25
用途：路演 PPT / 商业计划书的成本章节，以及"要不要自己做板"的决策依据
一句话结论：**按 1 万台量产规模测算，单片 BOM 约 ¥95，其中电子墨水屏占 47%。**

---

## 一、先说清楚这份测算的边界

| 项目 | 口径 |
| --- | --- |
| 测算对象 | 自画 4 层 PCB 的量产版整机（不是现在手上这块 Waveshare 开发板） |
| 批量假设 | 主力档 10000 台；另给 100 / 1000 / 50000 三档对照 |
| 价格口径 | 人民币、不含税、不含运费 |
| 不含项 | 模具摊销、认证费用、研发人力、云服务调用费 |
| 数据来源 | 立创商城 / 嘉立创阶梯价（2026-10 实查）+ 墨水屏原厂询价估算，逐项标注见第九节 |

**这份数字能拿去讲，但第九节的标注必须一起看。** 被问到"屏为什么是 45 块"时要能答出依据。

## 二、现有硬件底账

现在这块板是 Waveshare ESP32-S3-ePaper-3.97 整机开发板，不是自制板。下面是从板级配置与固件里逐条核对出来的实际用料，自制板就是照这个抄。

| 模块 | 具体型号 | 关键参数 |
| --- | --- | --- |
| 主控 | ESP32-S3-WROOM-1-**N16R8** | 16MB Flash / 8MB PSRAM，2.4G WiFi + BLE5，板载 PCB 天线 |
| 显示 | 3.97" 单色墨水屏 800×480 | SPI，4 灰阶，24P 0.5mm FPC，全刷 2.4–3.5s，静态功耗 0 |
| 电源 | **AXP2101**（TG28 兼容，I2C ID 0x4a） | 单节锂电充电 + 3 路 ALDO：功放 / codec / 屏 各 3.3V |
| 音频 codec | **ES8311** | I2S，16kHz 采样，模拟 MEMS 麦 + 内置 PGA |
| 功放 | **NS4150B** | D 类 3W/4Ω，GPIO39 使能 |
| 交互 | 三向侧键（UP/CENTER/DOWN）+ BOOT + **PWR** | PWR 走 AXP2101 PWRKEY，固件读不到 |
| 接口 | USB-C | 直连 S3 内置 USB Serial/JTAG，不需要 CH340 |

固件里已经固定的引脚分配（自制板必须保持一致，否则驱动代码要改）：I2C 41/42、I2S 13/14/47/21/48、EPD 11/12/10/9/46/3、按键 4/5/6/0、功放使能 39。

### 结构性结论

**屏 + 主控 + 电源 + 电池 四颗料合计 ¥77.8，占 81.9%。**

这意味着降本空间极其有限——剩下 11 项加起来才 ¥17。想显著降本只有两条路：

1. 压墨水屏价格（占 47.4%，是唯一有议价空间的项）
2. 砍电池改 USB 供电（省 ¥7.5，但产品形态退化）

## 四、规模效应

| 批量 | 单片 BOM | 主要变化 |
| --- | ---: | --- |
| 100 片 | ¥160–210 | 屏按零售价，PCB/SMT 工程费摊销高 |
| 1000 片 | ¥110–145 | 进入阶梯价，模具已摊销 |
| **10000 片** | **¥95** | **PPT 主口径** |
| 50000 片 | ¥85 | 屏谈到 ¥38，模组整盘价，结构件模具摊薄 |

规模曲线在 1000 片到 1 万片之间最陡（降幅约 25%），1 万片以上趋于平缓。这也是为什么 PPT 主口径取 1 万台——再往上讲需要采购协议做支撑，容易被质疑。

## 五、从 BOM 到零售价

| 层级 | 金额 | 说明 |
| --- | ---: | --- |
| BOM | ¥95 | 纯物料 |
| 组装 + 功能测试 | +¥6 | 含烧录、写 SN、屏幕点亮检查 |
| 包装（彩盒 + 挂绳 + 说明书） | +¥4 | 挂绳是老人场景的必需件 |
| 良率损耗 2% | +¥2 | 屏和 FPC 压接是主要损耗点 |
| **出厂完全成本** | **¥107** | |
| 建议零售价 | ¥299 | 硬件毛利率 **64%** |
| 若定价 | ¥399 | 硬件毛利率 **73%** |

**注意：硬件毛利率不等于生意毛利。** 这台设备每次按键都要调一次地图 API、每次语音对话都要走一次大模型，属于持续性运营成本，定价模型里必须单独留出这一块。

## 六、一次性投入

| 项目 | 费用 | 说明 |
| --- | ---: | --- |
| 外壳模具 | ¥1.5–3 万 | 一套注塑模，改结构就重开 |
| SRRC 无线型号核准 | ¥0.8–1.5 万 | 带 WiFi 必须做 |
| 3C 认证 | ¥0.5–1 万 | 含充电功能才需要 |
| PCB / 结构设计 | ¥1–3 万 | 外委或自研 |
| 打样迭代（按 3 版计） | ¥0.3–0.5 万 | 每版 5 片 + SMT 工程费 |
| **合计** | **¥4–9 万** | |

摊销到 1000 台是 ¥40–90/台，摊销到 100 台是 ¥400–900/台。**这个数字决定了小批量自制的经济性根本不成立。**

---

## 七、要不要自己画板

| 批量 | 建议 | 理由 |
| --- | --- | --- |
| 10–50 台 | **买开发板** | 自制的模具与认证摊销后单片成本高出 3 倍以上 |
| 50–500 台 | 开发板 + 3D 打印外壳 | 几百块能把观感和佩戴体验做出来，收益远大于自制 |
| 500 台以上 | 考虑自制 | 摊得平一次性投入，且能实现结构一体化 |

**自画 PCB 真正的收益不是省钱，是结构。** 现在这块开发板厚、有排针、有 HAT 接口，做不成能挂在老人脖子上的东西。如果产品定义就是"卡片式挂件"，那自制是形态需求，不是成本需求——这一点在 PPT 里讲清楚，比硬说"自制更便宜"更可信。

## 八、PPT 脚注与话术

### 脚注（必须写）

```
1. 按 10,000 台量产规模测算，BOM 成本不含税、不含运费
2. 未含模具（1.5–3 万）、SRRC 认证（0.8–1.5 万）等一次性投入
3. 墨水屏按国产原厂直采价估算，需签年度框架协议锁定
4. 未含云服务成本（语音模型 + 地图路径规划按调用计费）
```

### 主动讲的三个取舍

| 取舍 | 省多少 | 我们为什么不选 |
| --- | ---: | --- |
| 屏从 3.97" 换 2.9" | −¥18 | 路线卡从 5 行压到 2–3 行，老人看不清 |
| 砍电池改 USB 供电 | −¥7.5 | 失去随身形态，退化成桌面设备 |
| 用 S3 裸芯片替代模组 | −¥4 | 要自己做射频匹配并重做 SRRC，是伪降本 |

这段话的作用是：把"成本不是最低"转化成"我们清楚每个取舍的代价"。

## 十、自制板必须提前知道的四个坑

**1. 射频净空是最容易翻车的一环。**
用模组自带 PCB 天线，天线正下方和前方必须留净空（不铺铜、不放电池、金属件不贴近）。老人设备要挂脖子，挂绳孔和金属扣件如果落在天线正上方，SRRC 直接过不了。**结构设计和 PCB 布局必须同时做。**

**2. 屏的 FPC 是量产良率杀手。**
24P 0.5mm 间距，手工压接极易偏位；量产必须用带锁扣的座子并加 AOI 检测。这块屏还是唯一"贴装后不能返修"的件，拆一次基本报废。

**3. AXP2101 的上电时序不能自己发挥。**
现有固件里那三行（ALDO 设 3.3V → 使能三路 → 开电池检测）是照官方 TG28 BSP 抄的。顺序错了会出现在某些电池电压下起不来的偶发故障，量产阶段极难定位。

**4. 医疗宣称会改变认证路径。**
现在叫"导诊 / 路线卡"属于辅助工具，走普通电子产品认证即可。一旦对外说"辅助就医决策""用药提醒"，可能被归到二类医疗器械，注册周期以年计、费用以十万计。**这是产品定义问题，必须在画板之前定下来。**
