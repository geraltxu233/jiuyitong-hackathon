### 一屏出不完时的压缩规则

`CARD_LINES = 5`。超行时按顺序丢：站间步行换乘 → 上车点名称 → 末段下车站名。
**换乘站名与首末两段步行永不丢** —— 换乘站是全程唯一会迷路的地方，不砍。
行宽不再按 12 字硬截，改用像素口径（`LINE_BUDGET_PX=696`，汉字 56px / 半角 24px），
超宽只告警不截断，让固件画省略号——服务端硬切会切出"读得通但内容残缺"的句子。

## 后端

`backend/route_server.py`（纯标准库，无第三方依赖）

```
python route_server.py --port 8000
```

| 路由 | 用途 |
| --- | --- |
| `GET /api/transit?from=demo&to=hospital` | 板端接口，返回固定样例 |
| `GET /health` | 连通性探针 |
| `GET /` | 自检页（浏览器人工确认，不参与板端链路） |

设计要点：
- 固定样例的 `source` 写「演示数据 + 查询时间」，不冒充真实公交
- 每行强制裁到 12 汉字，最多 5 行，超长由后端截断（固件不换行，换行会压行）
- 单行请求日志带来源 IP 与耗时，联调时一眼看出是谁在打
- 请求行解析失败会打印原始字节并区分「疑似 TLS/代理」，排除浏览器中间层干扰

## 板端改动（4 个文件）

| 文件 | 改动 |
| --- | --- |
| `route_card.cc` | **新增**。`esp_http_client` 单次 GET，`cJSON` 解析，填 `RouteCard`；`RouteStart` 起 8 KB 栈一次性任务，不占用只剩 452 B 的语音任务栈 |
| `route_card.h` | 默认地址改为 `http://192.168.82.100:8000/...`；新增 `RouteStart` 声明 |
| `epaper_wifi.cc` | 新增 `RealRoute()`；菜单第一项改走真实请求；`PublishRoute` 增加"查询中/失败"两个分支；菜单加「样例路线卡（离线备用）」 |
| `main/CMakeLists.txt` | REQUIRES 增加 `esp_http_client json`（原本是 agent_link 的私有依赖，main 用不到） |

关键设计：
- **失败不编数据**：`code != 0` 或字段缺失一律 `kFailed`，`source` 放可直接显示的中文原因，屏上不出现假路线
- **state 最后写**：先填完 `title/lines/source` 再改 `state`，读侧看到 `kOk` 时数据已就绪
- **不阻塞控制任务**：`RouteStart` 立刻返回，界面先显示"正在查路线"，结果由后台任务写回，`ControlLoop` 下一轮 `Publish` 自动刷出
- **先挂断再请求**：`RealRoute` 开头 `EndCall()`，与内存约束一致
- 离线兜底：菜单第二项保留纯本地样例卡，网络挂了也能演
