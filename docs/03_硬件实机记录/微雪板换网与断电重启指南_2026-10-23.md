# 微雪墨水屏板（ESP32-S3 ePaper 3.97）换网与断电重启指南

日期：2026-10-23　|　适用固件：Agent_link `waveshare-epaper-397-wifi`

---

## 一、可以直接拔插开发板吗？

**可以，任何时候拔都安全**，只有两个注意事项：

| 事项 | 说明 |
|---|---|
| 烧录固件过程中不要拔 | 仅当电脑正在往板子写固件时拔会有变砖风险；平时运行中随时可拔 |
| 我这边的串口监听会短暂失联 | 监听脚本有自动重连逻辑，板子重新插回 COM6 后会自动恢复抓日志；电脑关机则监听自然停止，下次开机重新启动即可 |

**为什么拔电不丢配置**：WiFi 账号密码和平台绑定凭据（auth_key）都存在板子的 NVS 闪存里（非易失存储），断电不丢。固件源码依据：`transport_wifi.cpp` 中凭据通过 `SaveCreds()` 写入 NVS，开机时 `LoadCreds()` 读取。

## 二、脱离电脑，板子能独立工作吗？

**能。** 板子只需要 USB-C 口供 5V 电，接手机充电头或充电宝即可，不依赖电脑。

上电后板子自动执行：读 NVS 凭据 → 连上次那个 WiFi → 连平台 → MQTT 上线 → 恢复绑定状态。不需要重新配网、不需要重新绑定 Agent。

## 三、换网络的标准流程（重点）

### 原理

固件逻辑：开机后若存有 WiFi 凭据，会尝试连接 **20 秒**；连不上就**自动重新打开配网热点**（SoftAP `WavePaper397-XXXX`）。所以换网不需要任何按键组合，靠"让旧 WiFi 消失"来触发。

依据：`transport_wifi.cpp` 第 337-348 行——连接超时后 `StartProvisioning()`。

### 操作步骤

1. **关掉手机上的 MEIZU 热点**（必须先做，否则板子会照常连上旧热点，不会触发重新配网）。
2. 板子**断电再上电**（拔插 USB 即可，充电宝供电也行）。
3. 等 **约 20 秒**：板子尝试连旧 WiFi 失败后，自动开出热点 `WavePaper397-XXXX`，屏幕进入配网提示状态。
4. 手机连这个热点（iPhone 直接在下拉列表选，**不要手输 SSID**——上次就是手输丢了尾随空格导致失败）。
5. 弹出配网页（或手动访问 `http://192.168.4.1`），在下拉列表**选中新的 WiFi**，输密码，提交。
6. 板子自动连新 WiFi → 连平台 → MQTT 上线。**绑定关系保留，不用重新输六位码、不用重新绑 Agent。**
7. 若配网页打不开：复位板子再试（老问题——配网 HTTP 服务 socket 耗尽，重启即清）。

### 验证换网成功

- 屏幕显示 `Connected to the platform` + Agent 名字。
- 我这边串口日志出现 `[link] Online (phase=5)`。

## 四、换网后的注意点（针对今天的语音断连问题）

新 WiFi 的**上行带宽和稳定性**直接决定语音通话质量。今天的问题根因是 MEIZU 热点外网上行太差（音频上行只有 1.4KB/s，队列积压 2.6 秒后发送超时断线）。选新网络时：

1. **优先场馆/家庭固定宽带的热点**，比手机蜂窝热点稳得多。
2. 若只能用手机热点：手机放板子旁边、蜂窝信号满格、热点频段设 **2.4GHz**（ESP32-S3 不支持 5GHz）。
3. 通话中若报 `call ended or connection failed`，**等 1-2 分钟再按中键重试**——立即重试会撞平台 409 错误（旧语音会话残留未释放）。

## 五、快速参考卡

| 场景 | 操作 |
|---|---|
| 单纯断电重启 | 拔插 USB，自动恢复，无需任何操作 |
| 换 WiFi | 关旧热点 → 断电重上电 → 等 20 秒 → 手机连 `WavePaper397-XXXX` → 192.168.4.1 选新 WiFi |
| 重新绑定 Agent（一般不需要） | 菜单 Hold 中键 → `Reset platform activation`（注意：这会清绑定但**保留 WiFi**，需在平台控制台先解绑） |
| 配网页打不开 | 复位板子（清 socket），重试 |
| 通话一说话就断 | 换更强的网络源；或等 1-2 分钟再重试 |
